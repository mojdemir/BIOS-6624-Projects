# Project 3 – Risk factors and probability of stroke

This repository contains reproducible R code for the statistical
analysis for Project 3.

## Structure

background
  information provided by investigator (codebook and articles)

dataraw/
    Preliminary dataset provided by investigator.
    
datarprocessed/
    Dataset created for analysis.    
    
code/
    Scripts used to review preliminary data and run power calculations.

output/
    Tables produced by the scripts.

figures/
    Plots generated during preliminary data review.

report/
    Word document used to produce the final analysis section.
